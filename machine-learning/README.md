# Machine Learning Projects

A collection of machine learning projects covering predictive modelling, feature engineering, model evaluation and data-driven problem solving.

## Projects

### [Daily Active Customer Forecasting](daily-active-customer-forecasting/)

Forecasting daily active banking customers using XGBoost and statistical baselines.

The project explores time-series feature engineering, hyperparameter tuning and chronological model evaluation. It demonstrates the importance of comparing machine learning models against simpler forecasting approaches.

**Tools:** Python, Pandas, Scikit-learn and XGBoost.

More projects will be added as the portfolio develops.
