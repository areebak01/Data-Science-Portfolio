
# Data Visualization Projects

A collection of interactive data visualization projects that transform datasets into clear, engaging dashboards to explore patterns, compare trends and communicate insights.

## Projects

### [Chocolate Rating Dashboard](chocolate-rating-dashboard/)

An interactive dashboard exploring the factors associated with highly rated chocolate bars, including cocoa origin, ingredient combinations, cocoa percentage and flavour characteristics.

The dashboard features an origin filter, summary metrics, ratings over time, ingredient comparisons, a flavour word cloud and a heatmap of cocoa percentage versus ingredient count.

**Tools:** HTML, CSS, JavaScript and CSV.

[**View Live Interactive Dashboard**](https://areebak01.github.io/Data-Science-Portfolio/data-visualization/chocolate-rating-dashboard/)
