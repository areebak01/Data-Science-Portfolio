
# Data Analysis Projects

A collection of data analysis projects exploring real-world and synthetic datasets to uncover patterns, investigate relationships and communicate insights through data visualisation.

## Projects

### [Respiratory Sound Analysis](respiratory-sound-analysis/)

Exploratory analysis of respiratory sound recordings, patient demographics, diagnoses and annotated breathing cycles.

The project investigates demographic patterns, the distribution of respiratory conditions, and relationships between abnormal breathing sounds and patient characteristics. It also includes audio signal visualisations using waveforms and spectrograms.

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn and Librosa.

More projects will be added as the portfolio develops.
